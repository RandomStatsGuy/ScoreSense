# Phase 7 review: conditional portfolio selection

Baseline: merged phase 6, `c26dd59d2befa3f74aa9956bfd9ee748d52faa37`. This draft adds an optional **Choose a lineup set** disclosure to the approved Build → Review → Download workspace. Choose a count, one supplied opponent assumption and a goal: average scenario net, net balanced against downside, or coverage of a top finish. Review the proposal against a constrained projection-first set, inspect full rosters and save a personal research report. The build, collection, saved history and platform entries are unchanged.

This is conditional research under supplied assumptions. No calibrated contest-return forecast, authenticated settlement, accepted entry or untouched forward study is claimed. The exact [request and calculation contract](../DFS_CONTEST_PORTFOLIO_CONTRACT.md) defines loss units, target priority, bounds and solver proof scope.

## Reproduce

Use the normal repo virtual environment and installed frontend dependencies. In an isolated checkout, point Python at the existing host environment. Run the build before Python suites that import the static application.

```powershell
cd frontend
npm run build
cd ..
$env:PYTHONPATH = "."
$affected = Get-ChildItem tests/test_dfs*.py, tests/test_lineup*.py, tests/test_vegas*.py | Sort-Object FullName -Unique | ForEach-Object { $_.FullName }
.venv\Scripts\python -m pytest @affected -q
.venv\Scripts\python -m pytest tests/test_living_surfaces.py tests/test_product_constitution.py -q
$client = Get-ChildItem frontend/src -Recurse -File | Where-Object { $_.Name -match '^dfs.*\.test\.(js|mjs)$' } | ForEach-Object { $_.FullName }
node --test @client scripts/dev/layout_audit.test.mjs
node scripts/dev/dfs_portfolio_selection_tasks.mjs
node scripts/dev/dfs_flow_tasks.mjs --smoke
.venv\Scripts\python -m scripts.dev.verify_dfs_contest_portfolio --output outputs/dfs-phase7-engineering.json
```

To enumerate the full frontend suite, remove the `^dfs` filename prefix restriction above. Actual generated browser responses can be rebuilt with `python -m scripts.dev.build_dfs_contest_portfolio_browser_fixture`; they include runtime measurements and are not byte-identical between runs. Raw local logs/results remain under `outputs/`; only curated receipts and screenshots are included here.
