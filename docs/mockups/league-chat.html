Hard lines

  • No Chat tab. Home already exists. Do not add a destination.
  • Owner names lead. Team nicknames sit underneath.
  • Fun is a decision. Player chips open This Week or Free agents — not confetti.
  • Live draft stays board-first. Rooms that already have chat keep it.
