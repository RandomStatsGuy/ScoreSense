How the board is built

  • Site rank is the existing draft pool for this league: auction uses suggested bid, pick draft uses season P50. Keepers and taken names drop out. Top 80 only.
  • Context today is Hub PPR + draft type + team count + roster mins. Half PPR, standard, and dynasty are not a second pool yet — do not fake those ranks from the same PPR file.
  • A pick places the winner immediately above the loser. Already above is a no-op. Skip / too close only marks the pair seen.
  • Pairs are close scores (within 18%) and neighbors first. Same position, or FLEX across RB/WR/TE. Not a 599-card swipe deck.
  • Feed Draft writes the first 40 of your order into the existing nomination / pick queue. Site board stays the fallback. Dollars stay model fair value.
  • Not Vibes. No aura, no weekly P50 scale, no one-swipe-per-day lock. Buttons and keys exist; gesture is optional.
